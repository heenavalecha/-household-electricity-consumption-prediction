# Household Electricity Consumption Prediction Using Data Mining

## Project Overview

This project predicts household electricity consumption
using Data Mining and Machine Learning techniques.

The project uses Random Forest Regression to analyse
historical electricity usage and predict future consumption.

## Dataset

Dataset Name: Individual Household Electric Power Consumption

Source: UCI Machine Learning Repository

Dataset Link:
https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption

## Algorithm Used

Random Forest Regression

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- VS Code

## Project Steps

1. Dataset Collection
2. Data Cleaning
3. Data Preprocessing
4. Feature Engineering
5. Training and Testing
6. Random Forest Model Implementation
7. Model Evaluation
8. Data Visualization

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R-Squared Score

## Visualizations

The project generates:

1. Actual vs Predicted Electricity Consumption
2. Average Hourly Electricity Consumption
3. Random Forest Feature Importance

## Expected Business Benefits

- Predict future electricity consumption.
- Identify peak electricity usage hours.
- Reduce unnecessary electricity wastage.
- Help households manage electricity expenses.
- Support better energy management.

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the Python program:

python electricity_prediction.py

The dataset will be downloaded automatically.

The evaluation results and graphs will be
saved inside the results folder.

## Conclusion

This project demonstrates how Data Mining can
analyse historical electricity consumption and
predict future household electricity requirements.

It helps households understand their electricity
usage patterns and make better energy management decisions.
